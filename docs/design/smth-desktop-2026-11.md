# SMTH desktop — visual system

One system, three native renderers: the Android launcher (Kotlin views), the GTK
shell inside the live ISO (Python/GTK4) and the Windows launcher (Tk). They share
the palette, the wallpaper, the type roles, the icon language and the layout
model; each keeps its platform's own widgets and behaviour.

## Palette

| Ink | Hex | Role |
|---|---|---|
| Obsidian | `#09090B` | Field, taskbar base, window surfaces |
| Maroon | `#701B35` | Selection, active state, glass tint, crest of the wallpaper |
| Blush | `#F2C6D2` | Primary text, hairlines, highlights |

No other hue is painted anywhere. Transparency, blur and gradients are derived
from these three values only. Obsidian carries the majority of every screen;
maroon appears on selection and the lower glass edge; blush stays on text, icons
and 1 px edges.

## Wallpaper

`wallpaper.png` is generated by `tools/gen_assets.py:veil()`. Two dithered
maroon currents and a single blush crest cross a quiet obsidian field; the upper
left and the taskbar band stay dark so shortcuts and glass remain legible. It is
flat two-ink art by contract (`tools/test_palette.py`) and is bundled locally for
all three platforms.

## Type

- Doto / DotGothic16: brand mark, clock and the few display moments.
- Space Mono: every label, readout and control.
- Sizes: 7–10 sp labels, 10–13 sp headings, 20–30 dp display. Nothing larger.

## Icons

- Desktop/shortcut: 28–32 dp. Taskbar: 18–20 dp. Start menu: 20–24 dp.
- Real application icons are always the package's own icon, resolved from
  `PackageManager` (Android) or `GDesktopAppInfo` (Linux); Windows uses a drawn
  line set because its targets are system executables.
- SMTH system glyphs are an original line set: search, settings, wallpaper,
  all-apps, fallback. Windows adds twelve glyphs in one stroke language.
- No icon sits in a box; selection is a soft blush wash or a maroon tint.

## Layout

- Desktop: shortcuts in a single quiet column on the wallpaper, no tiles.
- Taskbar: 44–48 dp, glass, Start + search + pinned/running apps + tray.
- Start menu: 380–760 dp wide glass panel anchored above Start, with search,
  pinned row, all applications and real session controls only.
- Windows/taskbar spacing: 4 dp grid, 10–14 dp corners; one depth cue per surface.

## Motion

| Moment | Duration | Curve |
|---|---|---|
| Press feedback | 90–120 ms | decelerate, scale 0.96 |
| Start menu enter | 190 ms | ease-out (`cubic-bezier(0.32,0.72,0,1)` equivalent) |
| Start menu exit | 130 ms | decelerate, 10 dp nudge |
| Intro line reveal | 320–340 ms | ease-out |

Menu motion is interruptible, exits are ~30% shorter than entrances, and all of
it is disabled when animator scale / reduced-motion is off.

## Glass

A frosted pane with an obsidian-to-maroon vertical tint, a blush top sheen and a
1 px blush edge. Android samples a pre-blurred copy of the wallpaper (bundled,
so it works on API 23+ without a live blur pass); GTK and Tk use translucent
fills because their compositors do not expose backdrop blur to the toolkit.
