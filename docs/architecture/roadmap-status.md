## Current visual rules

- `tools/palette.json` is the only palette source: A (red), B (grey), AHIAN_A
  (purple), AHIAN_B (teal).
- No gradients, blur, glows, shadows, acrylic or translucent surfaces.
- Generated artwork must pass `tools/test_palette.py`; AHIAN artwork may only use
  the AHIAN pair.
- Doto, DotGothic16 and Space Mono ship in the image with their OFL licences.
- Reduce Motion disables decorative animation (honoured by `home.py` and AHIAN).

## Required before calling this finished

- Build and boot both ISOs; run `tools/check_budgets.py` on the real files.
- Complete the installer, persistence and recovery paths.
- Run the acceptance journeys and record evidence per item.
- Measure RAM, boot time, app launch, idle CPU on a documented 2 GB VM.
- Verify a signed extension end to end (build, install, mount, remove).
- Implement the PIN/pattern lock, or document a permanent decision to stay with
  PAM passwords.
