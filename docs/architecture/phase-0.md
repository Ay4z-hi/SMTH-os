# SMTH OS architecture — P0 foundations

## Vision
Windows-style desktop muscle memory on a modular, RAM-first live system, with
SMTH's black surfaces, grey neutrals, red accent and dot-matrix language.

## Palette contract
- Canonical source: `tools/palette.json`. Exactly four keys:
  - `A` = `#701b35` — the single accent (controls, focus, selected states),
  - `B` = `#f2c6d2` — grey neutral for the dot rhythm and unlit states,
  - `AHIAN_A` = `#7c4dff`, `AHIAN_B` = `#00c2a8` — AHIAN mode only.
- Core wallpaper/logo pixels: black, A or B only. AHIAN artwork: black plus the
  AHIAN pair only (`tools/test_palette.py` enforces both).
- UI text: white; surfaces: black. No intermediate shades in artwork, no alpha,
  gradients, blur or shadows.
- Runtime copies and GTK tokens are generated by `tools/gen_tokens.py`; never
  hand-edit generated copies.
- Recolour with `python3 tools/recolor.py '#RRGGBB' '#RRGGBB'` (rewrites text
  assets and regenerates artwork). AHIAN colours are edited in `palette.json`
  directly because they are not a global swap target.

## Typography
- Bundled offline in `usr/share/fonts/truetype/smth/`, with OFL licences:
  **Doto** (display/dot headings), **DotGothic16** (dot fallback), **Space Mono**
  (UI and code).
- Network font packages (`fonts-inter`, `fonts-jetbrains-mono`) were removed from
  the package lists; nothing downloads fonts at runtime.

## Design tokens
- 4 px spacing base; 1 px borders; window/flyout radius 8 px; controls 4 px; pills 999 px.
- Taskbar 48 px; icon 24 px; hit target 40 px (44 px in touch mode).
- Motion: 83/167/250/333 ms, cubic decelerate in and accelerate out. Reduce Motion
  disables all decorative motion.
- Signature pointer: hollow triangle (see `tools/gen_cursor.py`).

## Architecture decision — provisional
| Base | Advantages | Risks for this product | Decision |
|---|---|---|---|
| Debian Trixie minbase | glibc; broad GTK4, WebKit, PipeWire, NetworkManager, Wine/QEMU package support; amd64 and arm64 | Larger than Alpine/Tiny Core; package selection must be measured | **Default** |
| Alpine | Small base; musl; amd64/arm64 | glibc compatibility and desktop package integration add complexity; Wine/box64 support needs validation | Not selected |
| Tiny Core | Very small bootable base; extension model | GTK4/WebKit/PipeWire/NetworkManager would need substantial custom packaging | Inspiration for modularity, not base |
| Buildroot | Highly controllable appliance images | No general-purpose desktop ecosystem; app maintenance burden | Not selected |

Debian minbase is a starting decision, not proof of the size target. The closure is
measured by `tools/estimate_iso.py`; the real gate is `tools/check_budgets.py`.

## Image layout
- Core image: kernel/modules, live-boot, labwc, Waybar, GTK4 shell, core apps,
  Rust core binaries, bundled fonts.
- Signed `.smx` extensions: Browser (Firefox + WebKitGTK), Hypervisor (QEMU, Wine,
  Vulkan, KDE Connect/WayVNC), Creative, Office Lite, Developer (box64 on arm64).
- Live modes: Live, persistence, copy-to-RAM, safe graphics, recovery shell.
