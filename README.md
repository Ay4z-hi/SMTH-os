# SMTH OS v2

One code-base, two native targets: `amd64` (PC/UEFI) and `arm64` (ARM PCs, QEMU, SBCs). No cross-arch emulation in the build: CI uses a native x86_64 runner and a native arm64 runner.

## Upgrade your existing repo
1. Delete old `live/`, `overlay/`, `build.sh`, `.github/workflows/*.yml`. **Keep `freezerd/`.**
2. Unzip this kit into the repo root (keep `.github/`, `auto/`, `config/`, `arch/`, `scripts/`) and commit.
3. GitHub -> **Actions** -> **Build SMTH OS** -> **Run workflow**.
4. Download artifacts `smth-os-amd64` / `smth-os-arm64` (ISO + sha256). Tag `v0.2.0` to publish a Release.

Local build (Debian 13 or a debian:trixie container, native arch only):
    SMTH_ARCH=amd64 sudo -E ./scripts/build.sh
Test:
    qemu-system-x86_64 -enable-kvm -m 4G -smp 4 -bios /usr/share/OVMF/OVMF_CODE_4M.fd \
      -device virtio-vga-gl -display gtk,gl=on -cdrom out/smth-os-amd64.iso

## Tree
    auto/{config,build,clean}          live-build entry points (arch switch lives in auto/config)
    arch/{amd64,arm64}.list            arch-only packages (wine | box64)
    config/package-lists/              core, shell, apps, hypervisor
    config/hooks/normal/0100-system    services, mime, icon generation, dconf
    config/includes.chroot_after_packages/
      usr/local/bin/                   smth-open, smth-vm (hypervisor), smth-mode(d) (adaptive layout),
                                       smth-term-overlay, smth-glance, smth-corelink, smth-settings, smth-clock
      etc/skel/.config/                labwc, waybar (mobile+desktop), alacritty, fuzzel, mako, gtk-4.0 (DMM theme)
      usr/share/{themes,mime,applications}, usr/local/share/smth/icons/gen_icons.py
      etc/pipewire/                    low-latency audio
    scripts/{build,check-packages}.sh  build + package-name sanity check
    freezerd/                          (yours, unchanged)

## What is real vs. scaffold (read this)
| Feature | State |
|---|---|
| Dual-arch ISO, native CI | Written, **never built**. Expect a first-run fix (usually a package name; `check-packages.sh` reports them). |
| Desktop: labwc + waybar taskbar, snap keys, DeX-style hotplug switch | Works by design (`smth-mode` on udev DRM events) |
| Mobile layout: top status bar, bottom dock, on-screen keyboard (wvkbd) | Layout only. **No swipe gestures yet** (labwc has none; add a gesture daemon). |
| Hypervisor: ISO/IMG/BIN disk images -> QEMU (KVM when same arch) | Written |
| EXE | amd64: Wine. arm64: needs an x86_64 Wine build you drop in `~/.local/share/smth/wine-x64` (runs under box64) |
| APK | Needs Waydroid + binder: `sudo smth-install-waydroid` |
| x86-64 ELF on arm64 | box64 (in the arm64 image) |
| FEX-Emu | Not in Debian; not included |
| Terminal | Alacritty (OpenGL) + zsh, autosuggestions, syntax highlighting, fastfetch, drop-down toggle |
| Settings, Clock | Written from scratch (GTK4/libadwaita). Clock alarms are not persisted yet. |
| Camera, Gallery, Paint, Files | **Re-branded upstream apps** (Snapshot, Loupe, Drawing, Nautilus) with SMTH theme, icons and launchers. Writing these from scratch is a separate project each. |
| Icons | 10 custom SVGs generated by `gen_icons.py`; everything else falls back to Adwaita |
| CoreLink | v0 = KDE Connect protocol (files, clipboard, pairing) + wayvnc mirroring |
| Fonts | Drop Doto (OFL) TTFs into `.../usr/share/fonts/smth/`; until then falls back to DejaVu |
| Glass blur | labwc has no blur; panels use translucent fills |
| Real phones (GSI/Termux) | Not covered; the arm64 ISO targets UEFI ARM machines/VMs |
