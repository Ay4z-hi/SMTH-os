8. Not captured at runtime (environment blocker)
------------------------------------------------
`unahian` red screen and the restored desktop were NOT observed at runtime.
The emulator has no KVM (`-accel off`), and after the first successful run
its system_server was repeatedly killed by its watchdog during package
installs (`service list` collapsing to ~70 services, "Can't find service:
activity/package/window"), so the APK could not be relaunched afterwards.
The exit path exists in code (AhianExitOverlay, 3 s hold, theme restore)
and compiles; it is not runtime-verified.

Build provenance: the runtime evidence above came from intermediate debug
builds of this session that already contained the cascade, BSOD, countdown,
improved mode, Start-menu entry and search fixes. The final artifact adds the
launcher purple-teal desktop hook and the taller Start panel and was NOT yet
run on the device because the emulator could not relaunch it.

Windows EXE: not built or run (no Wine, PyInstaller cannot cross-build a
Windows EXE here, no tkinter/Xvfb for a headless Tk run). Only
`python3 -m py_compile launchers/windows/smth_launcher.py` was run.

Linux ISOs: not built or booted (no live-build, xorriso, qemu-system-*,
and no root for debootstrap/live-build). No ISO artifacts exist.

9. Linux scripts — real runtime run (headless, this machine)
------------------------------------------------------------
`ahian on` : prints cascade, "wants to make your life beautiful",
             countdown 9…1, writes ~/.config/smth/ahian and
             wallpaper=/usr/share/backgrounds/smth/ahian-teal.png,
             settings.json {"ahian": true}; exit 0.
`ahian unahian`: prints "looks like you dont like ahian", removes the flag
             and wallpaper preference, settings.json {"ahian": false};
             exit 0.
`smth-terminal` fed help/date/version/about/clear/ahian/unahian/exit:
             all commands answer, the Ahian sequence runs with the exact
             BSOD and exit copy, terminal returns to normal; exit 0.
This is script-level runtime, not ISO integration: nothing was booted.
