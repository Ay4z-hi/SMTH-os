# SMTH OS v6 pack (contains everything from v3, v4 and v5)
Upload the folders `auto`, `config`, `tools` and this file to the repo root. Same-name files are overwritten. Do NOT touch scripts/build.sh.
Then Actions -> Build SMTH OS -> Run workflow.
Palette: exactly two flat colours, orange #ff7a00 and blue #2f6bff, on black (white text). No gradients, glows or grey shades.
Change it any time:  python3 tools/recolor.py "#NEWA" "#NEWB"   (rewrites every file and regenerates the art)
Try `ahian` in a terminal. Lock password in the live image: live
